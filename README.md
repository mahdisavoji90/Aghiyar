# آگهی‌یار — Android-only MVP (v0.2)

## هدف
اپ مستقل Android بدون سرور اختصاصی. جست‌وجو و فیلتر روی داده ساختگی، ذخیره آگهی در Room، آمار قیمت، ورود اختیاری کلید API و اتصال مستقیم HTTPS به API رسمی کنار دیوار.

## پیش‌نیاز
Android Studio با JDK 17، Android SDK 35، اتصال اینترنت برای دریافت وابستگی‌های Gradle. پوشه پروژه را مستقیماً در Android Studio باز کنید، Gradle Sync و سپس Run را اجرا کنید. **این بسته APK کامپایل‌شده ندارد و بیلد آن در این محیط اجرا نشده است.** Gradle wrapper JAR در بسته نیست؛ Android Studio از Gradle نصب‌شده/مدیریت‌شده استفاده می‌کند. در صورت نیاز `gradle wrapper --gradle-version 8.9` را در محیط دارای Gradle اجرا کنید.

## حالت آزمایشی
برنامه به صورت پیش‌فرض در Demo باز می‌شود و درخواست HTTP به دیوار نمی‌فرستد. نمونه‌ها داده ساختگی‌اند و قیمت‌ها واقعی/به‌روز نیستند. فیلتر شهر، دسته و متن در حالت Demo روی داده نمونه اعمال می‌شود؛ برای مشاهده همه نمونه‌ها فیلدهای شهر و دسته را خالی کنید.

## اتصال واقعی
۱. در پنل کنار دیوار یک اپ بسازید و از پشتیبانی درباره دسترسی SEARCH_POST و محدودیت‌ها سؤال کنید.
۲. کلید محدود به SEARCH_POST بسازید. کلید را در کد، گیت یا پیام‌ها منتشر نکنید.
۳. داخل تنظیمات اپ، کلید را وارد کنید. برنامه آن را با Android Keystore (AES-GCM) رمزگذاری و محلی ذخیره می‌کند. **در برابر دستگاه روت‌شده یا بدافزار، حفاظت مطلق وجود ندارد.**
۴. حالت Demo را خاموش کنید؛ slug معتبر شهر و دسته را وارد کنید. شناسه‌های پیش‌فرض مثال‌اند و باید با لیست رسمی دیوار تطبیق داده شوند.
۵. جست‌وجو به `POST https://open-api.divar.ir/v2/open-platform/finder/post` با هدر `X-API-Key`، بدنه شامل `category`, `city`, `query: {}`, `query_text` ارسال می‌شود.
۶. داده‌ها از `posts` با فیلدهای `token`, `title`, `price.value`, `category`, `city` خوانده می‌شوند. قیمت‌های ناموجود `null` محسوب می‌شوند.

## سیاست سهمیه
SearchQuota در SharedPreferences به صورت محلی و قبل از درخواست یک تلاش را رزرو می‌کند. حداکثر ۱۰۰ تلاش برای **این نصب**؛ هیچ reset در UI وجود ندارد. شکست HTTP هم مصرف محلی دارد. این سقف نه نشان‌دهنده سهمیه واقعی دیوار است و نه بین دستگاه‌ها هماهنگ می‌شود. حذف داده برنامه/نصب مجدد آن را از بین می‌برد، پس این کنترل امنیت یا تضمین رعایت سهمیه سمت دیوار نیست. **از استفاده گسترده یا دوره‌ای از API جست‌وجو خودداری کنید.**

## امکانات خارج از محدوده
اعلان خودکار، زمان‌بندی، پایش مداوم، همگام‌سازی چند دستگاه، سرور، ثبت‌نام، API آگهی خصوصی، نمایش تصویر و جزئیات کامل آگهی. هرکدام نیازمند طراحی و مجوزهای مستقل است.

## ساختار
- `app/src/main/java/ir/aghiyar/app/MainActivity.kt`: UI Compose و وضعیت برنامه
- `Listing.kt`: مدل، Room و داده‌های آزمایشی
- `SecureKeyStore.kt`: رمزگذاری کلید روی دستگاه
- `DivarClient.kt`: HTTP و شمارنده محافظه‌کارانه

## هشدار
API دیوار محدودیت بسیار شدید (۱۰۰ فراخوانی مجموع طبق راهنما) دارد. قبل از توسعه محصول مبتنی بر جست‌وجوی مکرر، از تیم کنار دیوار مجوز و تأیید بگیرید. کلید سمت کلاینت برای اپ عمومی مناسب نیست؛ این معماری برای استفاده شخصی/آزمایشی پیشنهاد شده است.
